# 📱 KR Phone Store Web

A modern, responsive e-commerce platform built for selling mobile devices and accessories. 

## 🚀 Live Demo
<a href="https://krphonestore.phalla.lol/" target="_blank" rel="noopener noreferrer">👉 Click here to view the live site</a>

---

## ✨ Features
* **Product Catalog:** Browse the latest smartphones and accessories.
* **Search & Filter:** Quickly find devices by brand or price.
* **Shopping Cart:** Add/remove items and manage quantities.
* **User Authentication:** Secure login and registration.
* **Responsive Design:** Optimized for mobile, tablet, and desktop views.

## 🛠️ Tech Stack
* **Frontend:** React.js
* **Styling:** CSS3 / Tailwind CSS (or your specific library)
* **State Management:** Hooks (useState, useEffect) / Redux
* **Deployment:** Vercel / Netlify / GitHub Pages
